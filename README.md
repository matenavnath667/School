# BrightPath Academy — School Website

A responsive animated school website made with a single standalone HTML file. No build process or server required.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.

1. Open **Settings → Pages** in this repository: https://github.com/matenavnath667/School/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions** (not "Deploy from a branch").
3. Open the **Actions** tab and select **Deploy school website to GitHub Pages**.
4. If the previous run failed, open it and choose **Re-run jobs → Re-run all jobs**. Or push a new commit to `main` to trigger deployment.
5. Wait for the workflow to finish successfully, then visit https://matenavnath667.github.io/School/

## Before sharing publicly
Replace the BrightPath Academy demo name, sample descriptions, address, email and phone placeholders with real school information. The inquiry form is demo-only: it validates inputs in the browser but does not send or save submissions. The page uses Google Fonts, which requires internet access.
